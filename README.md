# Eeman Fatima — AI/ML Portfolio

A responsive personal portfolio built with Next.js, TypeScript, and Tailwind CSS.

## Run locally

1. Install Node.js 20+.
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000

## Customize before publishing

Open `app/page.tsx` and replace:
- `your.email@example.com` with your real email
- LinkedIn URL with your profile
- GitHub URL with your profile
- Any internship wording that needs exact company/job details
- Add real project screenshots/links when available

For a CV download, place your PDF at `public/Eeman-Fatima-CV.pdf` and add a link to `/Eeman-Fatima-CV.pdf`.

## Deploy

Push the project to GitHub and import the repository into Vercel. No backend or environment variables are required for this version.
